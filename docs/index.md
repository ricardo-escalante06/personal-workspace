# Personal Workspace

A personal productivity app for Mac and iPhone: tasks, projects with timelines, and a calendar in one place.

- Organize classes, lists and projects in folders, each holding tasks.
- Plan work sessions on a calendar next to your Google and iCloud events.
- Everything works offline and syncs between your devices.

It's a personal project, built and used by one person. The source code is on [GitHub](https://github.com/ricardo-escalante06/personal-workspace).
